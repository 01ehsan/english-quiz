# WordQuest ⚔️

برنامه آموزش لغات انگلیسی به‌صورت بازی، در یک فایل HTML (بدون نیاز به اینترنت یا نصب).

- ۳ سطح: ۲۰۰ / ~۵۰۰ / ~۱۰۰۰ کلمه پرکاربرد
- سؤال‌های ۴ گزینه‌ای: انگلیسی←فارسی، فارسی←انگلیسی، ترکیبی
- باز شدن سطح بعدی با ۸۰٪ کلمه‌های سطح قبل
- مرور اشتباهات، چالش ۶۰ ثانیه‌ای، استریک روزانه، XP و رتبه
- تم تیره و آبی روشن

## اجرا
فایل `index.html` را در مرورگر باز کن. پیشرفت در `localStorage` مرورگر ذخیره می‌شود.

## انتشار با GitHub Pages
Settings → Pages → Branch: `main` / root
